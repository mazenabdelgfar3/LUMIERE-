# LUMIERE- عيادات لوميير بجدة

الموقع الرسمي والصفحة التعريفية لعيادات لوميير للجلدية والتجميل بجدة (4 فروع: الروضة، طريق الملك، السامر، النسيم).

## التقنيات المستخدمة
- **Next.js 14 (App Router)**
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui**
- **خط المراعي (Almarai Font)**
- **n8n Automation Webhook** لحجز المواعيد والإشعار الفوري عبر تيليجرام
